# Day-1-Consistency-Program-
Day 1 Consistency Program:
public class Consistency {

    public static void main(String[] args) {

        String name = "Sarvesh";
        String goal = "Become a successful software developer";
        int day = 1;

        System.out.println("================================");
        System.out.println("       MY JAVA JOURNEY");
        System.out.println("================================");

        System.out.println("Name   : " + name);
        System.out.println("Goal   : " + goal);
        System.out.println("Day    : " + day);

        System.out.println();
        System.out.println("I will learn Java every day.");
        System.out.println("I will practice, not just watch.");
        System.out.println("I will make mistakes and learn from them.");
        System.out.println("I will stay consistent.");

        System.out.println();
        System.out.println("90 DAYS. ONE GOAL. NO EXCUSES.");
        System.out.println("I WILL BECOME A SOFTWARE DEVELOPER! 🚀");
    }
}
//output here check out 
String       → storing text
int          → storing a number
variable     → storing information
System.out   → displaying output
+            → joining text and variables
main()       → starting point of the program
